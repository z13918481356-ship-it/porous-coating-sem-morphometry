# Locked supervised U-Net protocol for FIB-SEM

Protocol frozen on 2026-08-30 before supervised training or U-Net test inference. The previously completed classical benchmark exposed 24 test-mask scores, but no FIB-SEM test image or mask may be used for U-Net fitting, early stopping, threshold selection, augmentation selection, or model selection.

## Data split

- Use the authors' official `ind_squares_train`, `ind_squares_validation`, and `ind_squares_test` arrays for HPC22, HPC30, and HPC45.
- Pool the three materials for one shared model while retaining material labels for stratified reporting.
- Expected counts: 180 training squares, 60 validation squares, and 60 test squares; each square is 256 x 256 pixels.
- Reference pore is fixed as `manual M=0`, based on the authors' `mean(~M)` porosity code.
- Do not discard low-contrast, single-class, edge-touching, or otherwise difficult official squares.

## Input and augmentation

- Convert the original 16-bit crop to float32 and rescale its 1st and 99th percentiles to [0, 1], independently per square.
- Training augmentation is limited to the eight dihedral transforms generated by 0/90/180/270-degree rotation and an optional horizontal flip.
- Validation and test inputs receive no stochastic augmentation.

## Model and optimization

- Use the repository's compact 2-level U-Net with one input channel, one logit output, and base width 16.
- Seed Python, NumPy, and PyTorch with `20260830`; request deterministic algorithms where supported.
- Loss: equally weighted binary cross-entropy with logits and soft Dice loss.
- Optimizer: AdamW, learning rate `1e-3`, weight decay `1e-4`.
- Batch size: 8; maximum 100 epochs.
- Select the checkpoint with the highest macro-average validation Dice across HPC22, HPC30, and HPC45 at a fixed sigmoid threshold of 0.5.
- Early stopping: 15 epochs without validation-macro-Dice improvement. No learning-rate or architecture sweep is permitted in this benchmark.

## Test and comparison

- Load the single selected validation checkpoint and run the 60 official test squares once.
- Report Dice, IoU, boundary F1 at 2-pixel tolerance, reference/predicted pore fraction, and absolute pore-fraction error overall and by material.
- Evaluate the already frozen dark-pore Otsu rule on the same 60 squares for a paired comparison. Do not optimize Otsu or the U-Net threshold on test data.
- Retain every official test square and publish per-square predictions and metrics.

## Interpretation

- The U-Net is considered a useful independent-mask segmentation model if overall median test Dice is at least 0.85 and every material stratum has median Dice at least 0.80.
- If the overall gate passes but a material gate fails, report material-dependent partial transfer.
- This benchmark tests segmentation on porous-polymer FIB-SEM only. It does not validate top-view coating segmentation or enter wetting/durability models.
